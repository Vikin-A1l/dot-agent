## 正式研究前仍需处理的边界

1. 通用 rule 模式的快速路径仍会采集一致性，不能将其直接当作完全关闭信号的对照。
2. Router 保存的默认阈值未实际替换策略表阈值，不能据传参声称完成阈值扫描。
3. 通用数值评分可能匹配答案中任意标准数值；没有 expected 的部分在线校验仅检查非空。
4. 当前请求时间在最终请求写账之前取值，不包括浏览器完整往返；启动预检用量也未进入请求 SQLite。
5. 缓存主要为精确匹配与 TTL；真实部署未验证本实现需要的 token 概率和 alpha-quantile。

以上边界在本次文档与交付整理中没有顺手重构。它们需要独立的实现、反例验证和固定对照，避免让代码组织工作改变研究协议。
