# 统一端云多 Agent 协作方案（设计草案）

日期：2026-10-21。状态：用户于 2026-10-21 确认方案 1；本副本作为实施依据。原草案保留。

## 1. 要解决的问题

团队已有多份能工作的实现，但任务编排、真实模型接入、证据选择和实验计量分散在不同目录。目标是让用户从同一入口提问，由同一套接口、调度和计量承接不同任务；不重新训练或合并模型权重。

沿用导师目标：在同题对照下，检验质量能否接近纯云，同时减少云 token 和完整响应时间。这里是目标，不是整合后必然成立的结论。

## 3. 三种整合方式

| 方式 | 收益 | 代价与判断 |
|---|---|---|
| 以干净 dot-agent 为底座，逐项接入证据流程 | 复用大部分已有代码；每一步可测试、可审查 | 推荐；需要明确资料输入和结果格式 |
| 整体迁入科研分支的当前文件 | 能快速拿到实验专用能力 | 未提交改动较多，且包含固定协议和研究数据依赖，不作为统一入口的直接底座 |
| 重新写一套或引入新的 Agent 框架 | 可重新组织接口 | 重复现有能力并增加依赖，本轮不采用 |

## 4. 推荐的运行方式

同一个系统使用本地小模型、云端大模型两个可替换后端。Agent 是分工角色，共用后端；调度、检索、校验和记账优先由程序完成。

### 没有资料的普通问题

复用现有快速路径。第一版保留已有分类与校验行为，不同时重写难度判断。现有一致性采样可能增加耗时，记录后另做消融，不预先宣称能够加速。

### 没有资料的复杂任务

复用现有本地拆分、依赖判断、同层并行、直接前驱结果传递、本地/云端分配和本地汇总。局部失败按已有升级规则处理。工具入口继续使用现有工具注册表；天气、提醒等演示实现不当作已连接真实外部服务。

### 带资料的问题：本轮新增的主要连接

1. 调用方显式传入带唯一编号的原文片段；第一版接受文本，不新增 PDF/Word 文件解析依赖。
2. 由 BM25 或本地小模型选择片段；小模型只返回编号，不改写证据、不生成最终答案。
3. 程序校验编号范围、重复、证据条数与字节预算，取回真实原文。
4. 云端读取问题和证据，返回答案及引用编号；程序校验引用是否来自实际提供的证据。此检查不等于事实正确性认证。
5. 证据选择或输出契约失败时，记录失败；允许一次流程级全文云端回退。全文无法装入已确认的上下文预算时明确失败，不静默丢资料。
6. 回退、底层重试和失败调用全部进入总用量与完整耗时；unknown usage 保留为未知，不估算成零。

初版默认资料选择器为 BM25，可显式选择本地模型。理由是旧先导尚未证明小模型选择优于简单检索。最终默认值由新对照实验决定。

## 5. 接口边界（以下字段为拟新增，当前尚不存在）

保留现有 `POST /api/run` 的 `{query}` 使用方式。新增可选 `sources` 和 `selector`，例如：

```json
{
  "query": "这份材料的实验结论是什么？",
  "sources": [
    {"source_id": "part-1", "text": "调用方提供的第一段原文"},
    {"source_id": "part-2", "text": "调用方提供的第二段原文"}
  ],
  "selector": "bm25"
}
```

- 没有资料：进入原有框架流程，不新增一次模型调用来选择流程。
- 有非空资料：进入证据问答；`selector` 允许 `bm25` 或 `local`，默认 `bm25`。
- 空资料列表、重复编号、非法选择器等请求在调用模型前返回清晰错误。
- 第一版带资料时不再叠加通用任务拆分，避免资料丢失与调用开销难以解释。纯云全文对照由评测入口显式运行。
- 结果复用 `answer`、`path`、`trace`、`metrics`，并追加实际提供的证据编号和答案引用；两者分别记录，不能把提供给模型的所有资料冒充其实际引用。
- 有资料的请求第一版绕过当前仅按问题匹配的缓存，防止同问题换资料却返回旧答案；正式对照关闭应用缓存。

上述测试针对当前干净底座，不能验证尚未实现的统一方案。

实施后的最小验收：

- 原普通问题、依赖顺序、同层执行、网关和来源基线测试继续通过。
- 有资料的问题经过实际主入口进入证据流程，BM25 与本地编号选择两条流程均能运行；不是只留一个未被调用的模块。
- 编号越界/重复、无效 JSON、引用不属于证据、选择失败、全文回退失败均有测试。
- 同问题更换资料不命中旧缓存；提供证据与模型引用分别可追踪。
- 所有新角色调用与失败回退计入用量；缺失 usage 不伪造；总时间覆盖本地、云端、重试与回退。
- 先用可控假模型验证请求和行为，再在另行确认的真实运行窗口下验证两个后端。假模型结果只证明工程行为。

科研对照分开报告：通用题比较纯本地/纯云/规则/信号；资料题比较全文云、固定规则、BM25、本地选证据。既有开发文档不变成未见测试集，旧结果不拼成新方案效果。新方案达到运行验收仍不等于性能目标或独立新颖性成立。
